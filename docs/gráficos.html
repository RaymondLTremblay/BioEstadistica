9.1 Gráficos Básicos con ggplot2

Este módulo es una introducción corta a la visualización de los datos. El paquete principal que se usa es ggplot2. La visualización de datos es un área especializada y no se le podrá hacer justicia al mismo tiempo que se estudia la estadística; aquí se presenta solo una introducción breve. La visualización ayuda a entender los datos, ya que su dispersión influye en qué prueba se puede utilizar y en el significado de los análisis.

ggplot2 implementa la gramática de gráficos (Grammar of Graphics), un marco conceptual propuesto por Leland Wilkinson en 1999. Hadley Wickham lo llevó a R en 2007, con la idea de construir cualquier gráfico por capas: datos + una estética (aes) + geometrías (geom_*). Hoy es uno de los paquetes más usados en R.

ggplot(datos, aes(x, y)) + geom_*() — construye gráficos por capas.

  • ggplot(datos, aes(...)): define los datos y qué variable va en cada eje/estética (color, forma, etc.).
  • + geom_*(): añade la geometría: geom_point() (puntos), geom_histogram() (histograma), geom_boxplot() (cajas), geom_smooth() (línea de tendencia), etc.
  • Idea clave: las capas se suman con +, apilando elementos sobre el mismo gráfico.

La información utilizada en este documento proviene en parte del libro Discovering Statistics using R por Andy Field, Jeremy Miles y Zoë Field (2014).

9.3 Regresión lineal

El primer gráfico es una regresión lineal. Para producirla se necesitan dos variables con datos continuos; seleccionamos el nivel de ansiedad y la nota del examen. Para hacer una regresión lineal que sigue el patrón \(y = mx + b\), se usa la función geom_smooth(method = lm), donde lm se refiere a modelo lineal (en inglés linear model). Nota que con ggplot2 hay que primero identificar de dónde provienen los datos (Exam_Anxiety), después cuáles son las variables que se van a utilizar (en este caso y = Exam, x = Anxiety), y por último qué tipo de gráfico se quiere, que en este caso es una regresión lineal.

library(tidyverse)
ggplot(Exam_Anxiety, aes(Anxiety, Exam,group=Gender))+ 
  geom_smooth(method=lm)+
  geom_point()# linear model

9.5 Salvar gráficos con ggsave

ggsave("figura.png") — guarda un gráfico en un archivo.

  • Qué hace: guarda el último gráfico dibujado; el formato lo determina la extensión (.png, .jpeg, .pdf, .tiff).
  • Más control: guarda el gráfico en un objeto (p <- ggplot(...)) y usa ggsave("figura.png", plot = p, width = ..., height = ...).

Para guardar un gráfico y usarlo en otros programas o presentaciones (por ejemplo, MS PowerPoint) se usa la función ggsave(). Se pone entre comillas el nombre que se quiere dar a la figura y la extensión indica el tipo de archivo (por ejemplo .tiff, .png, .pdf). Nota que aquí se guarda en una carpeta llamada “Graficos”; esto no es necesario: si no la incluyes, se guardará en la carpeta del proyecto.

ggsave() guarda el último gráfico que se dibujó. Para más control, guarda el gráfico en un objeto (p <- ggplot(...)) y luego usa ggsave("figura.png", plot = p).

ggsave("Iris_size.png") # .tiff, .png, .jpeg, .jpg

9.9 Histogramas

Un histograma es un gráfico que representa la frecuencia de los valores de un conjunto de datos. Por consecuencia, en el eje de x se encuentra una variable continua y en el eje de y la frecuencia. La frecuencia es la cantidad de veces que aparecen los valores de x en el conjunto de datos.

Se necesita el archivo DownloadFestival que se encuentra debajo la pestaña de Los Datos. El ejemplo proviene de Field et al. (2014).

Una bióloga estaba preocupada por los posibles efectos sobre la salud de quienes participan en un festival de música. Un año fue al Download Festival del Reino Unido y midió la higiene de los asistentes al concierto (n = 810) durante los 3 días del festival. Cada día intentaba encontrar a todas las personas que había censado el primer día. Los valores asignados iban de 0 a 4 según el nivel de limpieza, por cómo olían los participantes:
+ 0 = hueles como un cadáver. 
+ 4 = hueles a rosas dulces en un fresco día de primavera

La hipótesis es que la higiene personal de los asistentes al concierto disminuiría dramáticamente durante los 3 días del festival.

Construyendo histogramas y detectando valores atípicos. Nota los valores NA, estos son los participantes que no se pudieron encontrar en los siguientes días.

9.12 Detección valores sesgados o átipicos.

En la función de abajo, denominada Valoressesgados, uno puede determinar el porcentaje de valores atípicos (extremos). Como R no tiene esta función, se construye una para calcular los porcentajes. Si seleccionamos una de las columnas, el día 3 del concierto, vemos que hay 4% de los valores por fuera del intervalo de 95% y 2.4% por fuera del intervalo de confianza de 99%.

Valoressesgados<-function(variable, digits = 2){
  
  zvariable<-(variable-mean(variable, na.rm = TRUE))/sd(variable, na.rm = TRUE)
  
  IC95<-abs(zvariable) >= 1.96  # error de 95%
  IC99<-abs(zvariable) >= 2.58   # error de 99%
  IC999<-abs(zvariable) >= 3.29  # error de 99.9%
  
  ncases<-length(na.omit(zvariable))
  
  percentaje95<-round(100*length(subset(IC95, IC95 == TRUE))/ncases, digits)
  percentaje99<-round(100*length(subset(IC99, IC99 == TRUE))/ncases, digits)
  percentaje999<-round(100*length(subset(IC999, IC999 == TRUE))/ncases, digits)
  
  cat("Valor absoluto z-score mayor de 1.96 = ", percentaje95, "%", "\n")
  cat("Valor absoluto z-score mayor de 2.58 = ",  percentaje99, "%", "\n")
  cat("Valor absoluto z-score mayor de 3.29 = ",  percentaje999, "%", "\n")
}

Valoressesgados(FD$day3)
## Valor absoluto z-score mayor de 1.96 =  4.07 % 
## Valor absoluto z-score mayor de 2.58 =  2.44 % 
## Valor absoluto z-score mayor de 3.29 =  0.81 %

  • Cómo añadir el promedio de la variable con stat_summary.
  • Cómo conectar los promedios con una línea y cambiar su color.

9.14 La función stat_summary para calcular indices sumativos.

Nota que el promedio (mean) se añade como un punto, unido también por una línea, mediante el argumento fun de stat_summary. Los intervalos de confianza se añaden con fun.data = mean_cl_boot y geom = “errorbar”.

Se necesita la librería Hmisc para calcular los intervalos de confianza.

ggplot(hiccups, aes(y=Num_Hiccups,x=Intervention))+ 
  stat_summary(fun = "mean", geom = "point")

Añade la linea que conecta los promedios y los intervalos de confianza

ggplot(hiccups, aes(y=Num_Hiccups,x=Intervention))+ 
  stat_summary(fun = "mean", geom = "point")+ 
  stat_summary(fun = "mean", geom = "line", aes(group = 1),colour = "Red", linetype = "dashed")

Annade el interval de confianza

ggplot(hiccups, aes(y=Num_Hiccups,x=Intervention))+ 
  stat_summary(fun = "mean", geom = "point")+ 
  stat_summary(fun = "mean", geom = "line", aes(group = 1),colour = "Red", linetype = "dashed")+      
  stat_summary(fun.data = mean_cl_boot, geom = "errorbar", width = 0.2, colour="blue") + 
  labs(x = "Intervention", y = "Mean Number of Hiccups and 95% CI")

8.1 Estadística descriptiva

En los módulos de “Medidas de tendencia central” y “Medidas de dispersión” se explicó de dónde provienen estos parámetros y cómo calcularlos. En este módulo aprenderemos distintas funciones para calcularlos individualmente, y herramientas para obtenerlos todos (y otros) a la vez.

Los índices que veremos aquí incluyen

  • el promedio
  • la mediana
  • la desviación estándar
  • el mínimo
  • el máximo
  • los cuantiles
  • el índice de oblicuidad (en inglés “Skewness”)
  • el índice de curtosis (en inglés “Kurtosis”)

Aquí creamos un conjunto de 100 datos con un promedio de 100 y una desviación estándar de 10. Nota que la función set.seed() hace que la simulación comience igual cada vez que se corre, dando el mismo resultado. Esto se usa solo cuando uno está enseñando, para que los resultados sean consistentes.

8.4 Resumen estadístico de una variable

Para ver los estadísticos mencionados arriba (menos la moda, la oblicuidad y la curtosis) se puede usar la función stat.desc() del paquete pastecs. Para facilitar la lectura se usa la función round(x, 3); el 3 indica la cantidad de decimales que se muestran. Si no usamos round(), los valores aparecen en notación científica.

stat.desc(x) (paquete pastecs) — resumen estadístico completo.

  • Qué hace: para una o varias columnas numéricas, devuelve de una vez el n, la media, la mediana, la varianza, la desviación estándar, el error estándar, el intervalo de confianza y más.
  • Consejo: envuélvela en round(stat.desc(...), 3) para evitar la notación científica.

8.6 Los Cuantiles

Los cuantiles son los valores en intervalos específicos de una variable aleatoria continua. A menudo dan una mejor interpretación de la distribución cuando los valores no siguen una distribución normal. Típicamente, la distribución se divide en 4 partes (los cuantiles 0.25, 0.50 = la mediana, 0.75), que se conocen como cuartiles. Para más detalle pueden ver el siguiente enlace https://en.wikipedia.org/wiki/Quantile.

En el siguiente ejemplo se muestra cómo utilizar la función quantile y seleccionar los cuantiles deseados con el componente probs = c(…).

quantile(dlf$day1,probs=c(0.05, 0.1, 0.25, 0.5, 0.75, 0.95, 0.99), na.rm=TRUE)
##     5%    10%    25%    50%    75%    95%    99% 
## 0.5945 0.8490 1.3125 1.7900 2.2300 2.9055 3.3173

8.7 El índice de oblicuidad (Skewness)

Los términos oblicuidad (skewness) y curtosis (kurtosis), junto con el “método de los momentos” para describir la forma de una distribución, fueron introducidos por Karl Pearson a finales del siglo XIX. Pearson fue uno de los fundadores de la estadística moderna.

La oblicuidad (skewness) mide la asimetría de una distribución. Es positiva cuando la cola larga está a la derecha, negativa cuando está a la izquierda, y ≈ 0 cuando la distribución es simétrica.

El índice de oblicuidad describe la (a)simetría de una distribución alrededor de su promedio. Otra forma de describirlo es como el tercer momento, porque las diferencias respecto al promedio se elevan a la potencia 3.

La fórmula es la siguiente. Es muy similar a la de la varianza, pero note que las diferencias se elevan a la potencia 3. Para más información vea este enlace https://en.wikipedia.org/wiki/Skewness.

$\(\text{Oblicuidad} = \ frac{1}{N}\sum_{i=1}^N\left(\frac{x_i-\overline{x}}{\sigma}\right)^3\)$

Ahora se calcula el índice de oblicuidad y comparamos los valores. Como regla, cuando el nivel de oblicuidad está entre

  • -0.5 y 0.5 se considera dentro de una distribución simétrica (normal).
  • -1.0 y -0.5, o entre 0.5 y 1.0, los valores tienen una oblicuidad moderada.
  • Menor de -1.0 o mayor de 1.0 los datos tienen una oblicuidad grande.

Ahora evaluamos la oblicuidad de las tres distribuciones usando la función skewness del paquete e1071.

skewness(x) (paquete e1071) — índice de oblicuidad (asimetría).

  • Qué hace: cuantifica la asimetría de la variable x.
  • Cómo leer: ≈ 0 → simétrica; positiva → cola larga a la derecha; negativa → cola larga a la izquierda.

Para una distribución normal (simétrica) el valor es muy cercano a cero. Los datos sesgados a la derecha (con cola hacia la derecha) tienen oblicuidad positiva, y los sesgados a la izquierda, oblicuidad negativa.

library(e1071)
e1071::skewness(normal$value) # la oblicuidad de los datos de una distribución normal

e1071::skewness(obl_derecha$value) # sesgada a la derecha -> oblicuidad positiva
## [1] 0.8227041
e1071::skewness(obl_izquierda$value) # sesgada a la izquierda -> oblicuidad negativa
## [1] -0.6505105

8.8 El índice de curtosis (Kurtosis)

La curtosis (kurtosis) mide el peso de las colas de una distribución. En exceso, es positiva cuando las colas son pesadas (más valores atípicos que la normal) y negativa cuando son ligeras. La normal tiene curtosis en exceso ≈ 0.

El índice de curtosis describe las colas de una distribución. Otra forma de describirlo es como el cuarto momento, porque las diferencias respecto al promedio se elevan a la potencia 4. La curtosis mide la propensión a tener datos atípicos (colas pesadas).

La fórmula es la siguiente. Es muy similar a la de la varianza, pero note que las diferencias se elevan a la potencia 4. Para más información vea este enlace https://www.wikiwand.com/en/Kurtosis.

\[\text{Curtosis} = \frac{1}{N}\sum_{i=1}^N\left(\frac{x_i-\overline{x}}{\sigma}\right)^4\]

Primero voy a crear cuatro conjuntos de datos

  • con distribución normal
  • con distribución normal, con cola reducida
  • con distribución normal, con cola extendida
  • distribución uniforme
library(PearsonDS)
library(rmutil)

momentsR=c(mean=0, variance=1, skewness=0, kurtosis=2)
momentsE=c(mean=0, variance=1, skewness=0, kurtosis=4)  

normalR=rpearson(100000, moments=momentsR)

Ahora se calcula el índice de curtosis (en exceso) y comparamos los valores. Cuando se acerca a cero no hay exceso de curtosis, que es lo que uno espera de una distribución normal:

  • Menor de -1.0 los datos están muy aplanados (Uniforme, normalR).
  • Mayor de 1.0 (la distribución de Laplace).

Ahora evaluamos la curtosis de las distribuciones usando la función kurtosis del paquete e1071.

kurtosis(x) (paquete e1071) — índice de curtosis (peso de las colas).

  • Qué hace: mide qué tan pesadas son las colas de la variable x (curtosis en exceso).
  • Cómo leer: ≈ 0 → como la normal; positiva → colas pesadas (más atípicos); negativa → colas ligeras.

Para una distribución normal el valor es muy cercano a cero. Cuando hay exceso de colas (colas pesadas, como en Laplace) la curtosis es positiva; cuando las colas son ligeras (como en la uniforme) la curtosis es negativa.

library(e1071)
e1071::kurtosis(normal$value) # curtosis de los datos de una distribución normal
## [1] 0.03718564
e1071::kurtosis(normalR$value) # curtosis de los datos restringido
## [1] -1.008687
e1071::kurtosis(normalE$value) # curtosis de los datos con más colas
## [1] 1.005719
e1071::kurtosis(Unif$value) # curtosis de una distribución uniforme, colas ligeras
## [1] -1.200839
e1071::kurtosis(laplace$value) # curtosis de distribución Laplace, exceso de colas
## [1] 3.011958
